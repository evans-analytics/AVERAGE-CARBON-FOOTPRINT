
# 🌱 Food Carbon Footprint Analysis

## Overview
This project analyses the carbon footprint of common food items using R. 
It explores which foods and food categories produce the most CO2 emissions 
per kilogram of food produced.

## Tools Used
- **R** — statistical analysis
- **ggplot2** — data visualisation
- **dplyr** — data manipulation

## Key Findings
- Beef produces the highest CO2 emissions (~60kg per kg of food)
- Plant-based foods like lentils and bananas produce less than 1kg of CO2
- Meat as a category produces on average 25x more emissions than plant foods

## Relevance
This analysis is directly relevant to food environmental labelling research, 
exploring how different food choices impact carbon emissions — supporting 
more sustainable consumer decisions.
